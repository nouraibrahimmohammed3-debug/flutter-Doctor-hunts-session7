# Doctor Hunt 🩺

تطبيق Flutter للبحث عن الأطباء وحجز المواعيد وإدارتها، مع واجهات منفصلة للمريض والمشرف، ودعم اللغتين العربية والإنجليزية.

## المميزات

### المريض
- إنشاء حساب وتسجيل الدخول بالبريد الإلكتروني أو حساب Google.
- استعادة كلمة المرور وتغييرها.
- استعراض الأطباء والبحث بالاسم أو التخصص.
- تصفية الأطباء حسب التخصص وترتيبهم حسب التقييم أو الشعبية.
- عرض تفاصيل الطبيب ورسوم الكشف والتوافر.
- إضافة الأطباء إلى المفضلة.
- اختيار موعد متاح وتأكيد الحجز.
- استعراض المواعيد وإلغاؤها.
- تقييم الطبيب بعد اكتمال الموعد.
- تعديل الملف الشخصي والصورة واللغة وتفضيلات الإشعارات.

### المشرف
- إضافة الأطباء وتعديل بياناتهم وصورهم.
- تفعيل إتاحة الطبيب أو تعطيلها.
- تحديد أيام العمل وساعات الدوام ومدة الموعد.
- استعراض الحجوزات وإدارة حالاتها.
- تعديل موقع العيادة.

### مميزات مشتركة
- شاشات البداية والتعريف بالتطبيق.
- اختيار الدور النشط للمستخدم.
- توجيه المستخدم حسب حالة تسجيل الدخول وصلاحياته.
- دعم العربية والإنجليزية واتجاهي RTL وLTR.
- تحديث البيانات لحظيًا باستخدام Firestore.

### المعمارية

تستخدم ميزة المصادقة ثلاث طبقات:

- **Presentation:** الشاشات وإدارة الحالة.
- **Domain:** الكيانات وعقود المستودعات وحالات الاستخدام.
- **Data:** تنفيذ المستودعات ومصادر بيانات Firebase والتخزين المحلي.

تستخدم ميزات أخرى خدمات مباشرة للوصول إلى البيانات، لذلك يختلف مستوى فصل الطبقات بين الميزات.

تُسجَّل الاعتماديات في:

```text
lib/apps/core/di/injection_container.dart
```

وتُعرَّف المسارات وسياسات إعادة التوجيه في:

```text
lib/apps/core/router/app_router.dart
```

## متطلبات التشغيل

- Flutter SDK متوافق مع قيد Dart المحدد في `pubspec.yaml`:
  ```yaml
  sdk: ^3.9.0
  ```
- Android SDK ومحاكي أو جهاز Android فعلي.
- مشروع Firebase مع تفعيل الخدمات المستخدمة.
- Firebase CLI عند الحاجة إلى نشر قواعد الأمان.

إعداد Firebase الموجود يستهدف Android. تشغيل منصات إضافية يحتاج إلى إعداد Firebase والمتطلبات الخاصة بكل منصة.

## الإعداد والتشغيل

### 1. تثبيت الحزم

من مجلد المشروع:

```bash
flutter pub get
```

### 2. إعداد Firebase

أنشئ مشروع Firebase أو استخدم مشروعًا لديك صلاحية الوصول إليه، ثم:

1. أضف تطبيق Android بمعرّف الحزمة:
   ```text
   com.example.doctor_hunt
   ```
2. ضع ملف الإعداد المناسب في:
   ```text
   android/app/google-services.json
   ```
3. فعّل تسجيل الدخول بالبريد الإلكتروني وكلمة المرور، وبحساب Google.
4. اضبط بصمات SHA المطلوبة لتسجيل الدخول بحساب Google.
5. أنشئ قاعدة Cloud Firestore وحاوية Firebase Storage.
6. أكمل إعداد Firebase Cloud Messaging إذا أردت استخدام وظائفه.

تُهيّأ Firebase حاليًا داخل `main.dart` باستخدام:

```dart
await Firebase.initializeApp();
```

### 3. نشر قواعد الأمان

يتضمن المشروع:

- `firestore.rules` للتحكم في الوصول إلى البيانات.
- `storage.rules` للتحكم في قراءة الصور ورفعها.
- `firebase.json` لتحديد ملفات القواعد.

بعد تسجيل الدخول إلى Firebase CLI، انشر القواعد إلى مشروعك:

```bash
firebase deploy --only firestore:rules,storage --project YOUR_FIREBASE_PROJECT_ID
```

استبدل `YOUR_FIREBASE_PROJECT_ID` بمعرّف مشروع Firebase.

### 4. تجهيز حساب المشرف

الحسابات الجديدة تُنشأ بدور `patient`. لإعداد مشرف، عدّل مستند المستخدم من بيئة موثوقة مثل Firebase Console، وأضف `admin` إلى قائمة `roles` مع ضبط `isActive` على `true`.

لا تسمح قواعد التطبيق للمستخدم بترقية صلاحياته بنفسه.

### 5. تجهيز الحجز

من حساب المشرف:

1. حدّد موقع العيادة.
2. أضف طبيبًا وحدّد رسومه.
3. اضبط أيام العمل وساعات الدوام ومدة الموعد.
4. فعّل إتاحة الطبيب للحجز.

### 6. تشغيل التطبيق

```bash
flutter run
```

## البيانات والحجز

| المجموعة | الغرض |
|---|---|
| `users` | ملفات المستخدمين والأدوار والتفضيلات والمفضلة |
| `doctors` | بيانات الأطباء والتوافر والتقييمات وعداد الحجوزات |
| `appointments` | الحجوزات وحالاتها وبياناتها |
| `booking_slots` | تتبع إشغال الفترات الزمنية |
| `reviews` | تقييمات المواعيد المكتملة |
| `settings` | إعدادات العيادة |

يستخدم الحجز **Firestore Transactions** لتحديث الموعد والفترة الزمنية وعداد حجوزات الطبيب معًا، ومنع حجز الفترة نفسها أكثر من مرة.

حالات الموعد:

```text
upcoming → completed
upcoming → cancelled
```

- إكمال الموعد متاح للمشرف بعد انتهاء وقته.
- التقييم متاح لصاحب الحجز بعد اكتماله، مرة واحدة.
- تعديل جدول الطبيب يتطلب عدم وجود حجوزات نشطة.
- تُخزَّن أوقات الحجوزات بتوقيت UTC، وتُعرض وفق توقيت الرياض.
- العملة المخزنة للحجز حاليًا هي `USD`.

## الصور

تُرفع الصور إلى Firebase Storage في المسارات:

```text
doctor_photos/
profile_photos/{userId}/
```

الأنواع المدعومة: JPEG وPNG وWebP.

تشترط قواعد التخزين أن يكون حجم الملف أقل من 5 ميغابايت. رفع صور الأطباء يتطلب مستخدمًا نشطًا بصلاحية المشرف، ورفع صورة الملف الشخصي متاح لصاحب الحساب النشط.

القواعد الحالية تمنع تعديل ملفات الصور الموجودة أو حذفها.

## الترجمة وتوليد الملفات

مصادر الترجمة:

```text
lib/i18n/ar.i18n.json
lib/i18n/en.i18n.json
```

بعد تعديل النصوص، أعد التوليد:

```bash
dart run build_runner build --delete-conflicting-outputs
```

تُحفظ الملفات المولدة داخل `lib/generated/`، وتُضبط خيارات التوليد في `build.yaml`.

لتوليد أنماط النصوص:

```bash
dart run lib/generated/generate_styles.dart
```

عدّل مصادر التوليد بدلًا من تعديل الملفات المولدة يدويًا.
