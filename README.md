# Doctor Hunt

تطبيق Flutter للبحث عن الأطباء، عرض ملفاتهم، وحجز المواعيد.

## التدفق الحالي

1. Splash
2. Onboarding
3. Choose Role
4. Home
5. Find Doctors
6. Doctor Details

## التشغيل

```bash
flutter pub get
flutter run
```

بيانات الأطباء التجريبية موجودة في:

```text
lib/apps/features/auth/data/service/doctors_service.dart
```

ومسارات الصور معرفة في:

```text
lib/generated/image_assets.dart
```
